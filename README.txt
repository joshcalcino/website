Josh Calcino - personal website

Static HTML, CSS, and JavaScript. No package installation or build service is needed.
Edit the HTML files directly to update page text. Shared styling and gallery behavior
are in assets/site.css and assets/site.js. Images are served locally.

Preview locally: python3 -m http.server 8000 --bind 127.0.0.1

Content and design reconstructed from archived joshcalcino.com pages. Original prose
is preserved; the unfinished AB Aur duplicate is omitted at Josh's request.
The IRS48 simulation video was recovered from the original Wix page data.
